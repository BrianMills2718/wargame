# Wargame

Generative AI geopolitical wargame: a programmatic state engine plus LLM adjudication. Players command in natural language; Python holds the state and the LLMs only suggest. Start with [AGENTS.md](AGENTS.md) for the architecture and [docs/index.md](docs/index.md) for the reading order.

Run the quick check with `make check`; run the whole test suite with `make full`.
